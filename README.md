# Circuitries — Android app

Πρακτικά ηλεκτρικά κυκλώματα: οικιακές εγκαταστάσεις, επισκευές στο σπίτι, ηλεκτρονικά,
πίνακες αυτοματισμού 24 V DC, κινητήρες, φωτοβολταϊκά και βιώσιμη ενέργεια — εκτός σύνδεσης, στο κινητό σου.

## Λήψη

**[⬇️ Circuitries-latest.apk](https://github.com/LabisKouzoumpasis/Circuitries-apk/releases/download/latest/Circuitries-latest.apk)**

1. Άνοιξε τον σύνδεσμο από το κινητό και κατέβασε το αρχείο.
2. Πάτα το αρχείο και επίτρεψε την εγκατάσταση από τον browser, αν σου ζητηθεί.
3. Οι επόμενες ενημερώσεις γίνονται μέσα από την εφαρμογή: όταν υπάρχει νέα έκδοση εμφανίζεται κουμπί **«Ενημέρωση»**.

Όλες οι εκδόσεις: [Releases](https://github.com/LabisKouzoumpasis/Circuitries-apk/releases).
